# Work Time Tracker

This is a simple web-based **Work Time Tracker** app that allows you to track your work hours, calculate earnings, and monitor progress toward daily and monthly goals.

## Features

- Select month/year to display and track daily work entries
- Set custom rates for different work types (FL/DS)
- Track and summarize daily, monthly, and annual earnings
- Quick stats for today and monthly summaries
- Call statistics and goals
- Responsive user interface with [Tailwind CSS](https://tailwindcss.com/) and [Font Awesome](https://fontawesome.com/)

## How to Use

1. **Clone or download this repository.**
2. Open `index.html` in your browser.
3. Or, enable [GitHub Pages](https://pages.github.com/) on this repository and view it live at  
   `https://<username>.github.io/<repo>/`

## Customization

- You can edit the rates, goals, and other settings within the page UI.
- No backend is required; all data is handled locally in the browser session.
