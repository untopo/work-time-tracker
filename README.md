# Work Time Tracker

A modern web-based **Work Time Tracker** application that helps you track your calls, manage rates, and monitor your earnings with real-time statistics.

## Features

### Call Management
- Track call duration with start/stop functionality
- Add manual call entries with custom duration
- Edit or delete existing calls
- Real-time earnings calculation during calls

### Rate System
- Create custom rates with names and hourly amounts
- Flexible rate management (add/delete rates)
- Apply different rates to different calls

### Statistics Dashboard
- View average call duration
- Track progress toward daily goals
- Monitor monthly earnings (first/second half split)
- Real-time total time and earnings calculations

### User Interface
- Clean, modern design with [Tailwind CSS](https://tailwindcss.com/)
- Responsive layout for all devices
- Dark/Light mode toggle
- Intuitive icons with [Font Awesome](https://fontawesome.com/)

### Data Management
- Automatic local storage
- Persistent data across browser sessions
- No backend required

## How to Use

1. **Access the Application**
   - Clone this repository, or
   - Fork it to your GitHub account
   - Open `index.html` in your browser
   - Or enable [GitHub Pages](https://pages.github.com/) and access at:  
     `https://<username>.github.io/work-time-tracker/`

2. **Getting Started**
   - Add your rates (e.g., "Standard Rate", "Premium Rate")
   - Set your daily earnings goal
   - Start tracking calls!

3. **Using the Timer**
   - Click "Start Call" to begin tracking
   - Watch real-time earnings accumulate
   - Click "End Call" to save
   - Or use "Add Call" for manual entries

## Customization

- Dark/Light mode preference is automatically saved
- All data is stored locally in your browser
- Clear browser data to reset all settings
