# Work Time Tracker

A modern **web-based time and call tracker** that helps you manage rates, monitor earnings, and view real-time statistics.  

## Features

### Call Management
- Start/stop calls with a live timer  
- Add manual entries with custom date, time, and duration  
- Edit or delete existing calls  
- Real-time earnings calculation during live calls  

### Rate System
- Create custom rates with name and per-minute amount  
- Easily add or remove rates  
- Apply different rates to different calls  

### Statistics & Metrics
- Daily stats: number of calls, average duration, total earnings  
- Daily goal tracking with dynamic progress bar  
- Weekly, monthly, and payment cycle metrics  
- Automatic estimation of remaining time to reach goals  

### Payment Cycles (new)
- Enable/disable payment cycle tracking  
- Create, edit, or delete cycles with start, end, and pay dates  
- Calculate total earnings per cycle  
- Countdown of days left until cycle end and payday  

### User Interface
- Modern, responsive design with [Tailwind CSS](https://tailwindcss.com/)  
- Persistent dark/light mode support  
- Intuitive icons with [Font Awesome](https://fontawesome.com/)  
- Dynamic tables with inline edit and delete actions  

### Data Management
- Automatic **localStorage** persistence  
- Export/import data in JSON format  
- Clean up old records (older than 3 months)  
- Visual indicator of local storage usage  

## How to Use

1. **Access the Application**
   - Clone this repository, or  
   - Fork it to your GitHub account  
   - Open `index.html` in your browser  
   - Or enable [GitHub Pages](https://pages.github.com/) and access at:  
     `https://<username>.github.io/work-time-tracker/`

2. **Getting Started**
   - Add your rates (e.g., “Standard”, “Premium”)  
   - Set your daily earnings goal  
   - Start tracking calls!  

3. **Using the Timer**
   - Click **“Start Call”** to begin  
   - Watch your earnings grow in real time  
   - Click **“End Call”** to save  
   - Or use **“Add Call”** for manual entries  

## Customization
- Dark/Light mode preference is saved automatically  
- All data stays in your browser  
- Clear local storage to reset the app
